# VZZN Studio Meta Legal Pages

Routes:
- `/privacy`
- `/data-deletion`

## Easypanel

Deploy this folder from a Git repository using the included `Dockerfile`.

Container port: `80`

Recommended domain example:

`legal.automatemystartup.com`

Then use:

- Privacy Policy URL: `https://legal.automatemystartup.com/privacy`
- Data Deletion Instructions URL: `https://legal.automatemystartup.com/data-deletion`
